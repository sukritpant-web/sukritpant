Business Intelligence - Historical Timeline

1865

Richard Millar Devens

First used "Business Intelligence" in Cyclopædia of Commercial and Business Anecdotes

Described Sir Henry Furnese (banker) profiting from information gathering

Acting on information before competition

1958

Hans Peter Luhn (IBM)

Computer scientist who described BI potential through technology

Laid foundation for modern BI concepts

BI History Continued

1968

Specialized Skills Era

Only individuals with extremely specialized skills could translate data into usable information

Limited accessibility to data insights

1980s

Commercial Growth

BI vendors grew as businesses discovered BI value

Development of tools for accessing and organizing data

Focus on simpler data organization methods

Modern BI evolved from Decision Support System databases

Modern BI Development

1988

Rome Conference Milestone

The Multiway Data Analysis Consortium international conference

Sparked creation of numerous BI businesses

Each offered new BI tools and approaches

Two Basic BI Functions emerged:

  • Producing data and reports
  • Organizing and visualizing data in presentable ways

Late 1990s-2000s: Democratization

  • Simplified tools for decision makers
  • Self-sufficient business users
  • Direct data interaction capabilities

Business Intelligence Definition

Formal Definition (Sabherwal 2007, 2008):

"Business Intelligence (BI) is providing decision makers with valuable information and knowledge by leveraging a variety of sources of data as well as structured and unstructured information."

BI Transformation Process:

Data → Information → Knowledge → Decisions → Action

Core Purpose: Enable informed decision-making through data-driven insights

Business Intelligence vs Data Analytics

Business Intelligence (BI):

  • Process to turn data into meaningful information
  • Uses tools and techniques for data transformation
  • Focuses on reporting and visualization
  • Supports operational decisions

Data Analytics (DA):

  • Tools to explore past data
  • Gain insights into future business decisions
  • Emphasizes predictive capabilities
  • Statistical and mathematical analysis focus

Both complement each other in modern organizations

Business Intelligence System

BIS Definition:

An umbrella term that combines:

People
Processes
Architectures
Tools
Databases
Analytical tools
Applications
Methodologies

Key Characteristic:

BIS is a "content-free expression" - it means different things to different people based on their organizational context and needs

Four Capabilities of BIS

1. Data Integration

  • Combining data from different sources
  • Creating single, unified view
  • Ensuring data consistency

2. Organizational Memory (OLTP)

  • Accumulated organizational data/knowledge
  • Historical information repository
  • Institutional knowledge preservation

3. Insight Creation

  • Tools for manipulating, mining, analyzing data warehouse data
  • Pattern recognition and discovery
  • Knowledge extraction processes

4. Presentation

  • Interpreting data in visual terms
  • Putting information into visible form
  • User-friendly data representation

Data Analysis Types

1. Descriptive Analytics

What happened?

  • Historical data analysis
  • Reporting and dashboards

2. Diagnostic Analytics

Why did it happen?

  • Root cause analysis
  • Correlation identification

3. Predictive Analytics

What will happen?

  • Forecasting and modeling
  • Trend analysis

4. Prescriptive Analytics

What should we do?

  • Optimization recommendations
  • Decision support
